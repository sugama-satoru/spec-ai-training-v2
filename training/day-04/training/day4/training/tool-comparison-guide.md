# AIツール比較・体験まとめ（Day1-3）

| 業務 | おすすめツール | 理由 |
|---|---|---|
| 市場調査 | ChatGPT / Gemini（Deep Research） | 複数サイトを横断調査し出典付きでレポート化。深掘りはChatGPT、全体設計はGeminiが向く |
| 文章作成 | Claude | 文体・トーンが安定し、推敲や言い回しの調整に強い。全体的に最も使いやすいと感じた |
| 資料構成 | Gemini | プロセス全体や業務フローの組み立てが上手。構成の設計役に向いている |
| データ分析 | ChatGPT（ファイル分析） | ファイルをアップロードして集計・可視化ができる |
| ブレスト | ChatGPT | 1つの論点を1問1問掘り下げる発想出しが得意 |
| コード生成 | Claude Code / Codex / Cursor | コーディング特化のエージェント型ツール（Day1-3では未使用のため要検証） |


### Day1-3 で実際に使った感想

3ツールを使い比べた中で、**Claudeが最も使いやすいと感じた**。文章作成のように仕上げの質が問われる作業で特にその差を実感した。一方で、ChatGPTとGeminiもそれぞれ明確な強みがあり、「1つに絞る」より用途で使い分けるのが自分には合っていると考えるようになった。

### 各ツールの得意・不得意の自分なりの評価

| ツール | 得意 | 向いている用途 |
|---|---|---|
| Claude | 全体的な使いやすさ、文章の仕上げ | 文章作成、日常的な作業全般 |
| ChatGPT | 深掘り。1問1問を掘り下げる力 | 面接質問の作成、準備物の洗い出しなど、個別の論点を深める作業 |
| Gemini | 設計力。プロセス全体の組み立て | 業務フローの設計、手順全体の構成づくり |

自分なりの結論として、**「深掘りのChatGPT」「設計のGemini」「仕上げのClaude」**という役割分担が見えてきた。準備物の洗い出しのような"中身を詰める"作業はChatGPT、業務フローのような"全体を組む"作業はGeminiが強い、という対比が特にしっくりきた。
