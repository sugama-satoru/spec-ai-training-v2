## AI用語まとめ

| 用語 | 説明のポイント |
|---|---|
| Token | AIが文章を理解し、生成するための最小単位。モデルによってどこでトークンを区切るかは異なる。|
| Context（コンテキストウィンドウ） | AIが一度に覚えていられる情報量であり、古いものから順々に忘れていく。|
| Prompt | AIへの指示・入力文のことで出力結果に関わる。 |
| LLM | 大規模言語モデル。対話型AIの中核を担う技術。|
| LLM kinds | LLMのモデルの種類や、会話特化、コード特化、軽量LLMなどの特化型AIの種類。|
| AI Agent | 目標達成のために自律的に複数の行動を進めるAI　|
| Autonomous AI | 人間の指示なしに目標→計画→実行→評価を行うAI |
| RAG | 外部資料などから参照し根拠付きで答えるAI技術。ハルシネーションを起こしにくい。 |
| OCR | 画像データから文字情報を読み込む技術 |
| Plan Mode | 実行の前に計画を立てるモードで、手順確認ができるためミスが減り複雑なタスクに向いている。 |
| Skills | AIやシステムが外部のツールや機能を追加しできることを拡張する仕組み。|
| AGENTS.md | AIエージェントの専用ルールや行動指示ファイル |
| CLAUDE.md | AGENTS.mdのCLAUDE版　|
