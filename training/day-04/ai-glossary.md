| 用語 | 説明のポイント |
|---|---|
| Token | AIが文章を処理する最小単位。日本語なら1～数文字、英語はほぼ単語ごとに分けられる。 |
| Context（コンテキストウィンドウ） | AIが一度の会話で覚えていられる情報量であり、トークン数によって測られている。超えたトークンから忘れるようになっている。|
| Prompt | AIへの指示・質問などの入力文のことで、プロンプトの質次第で出力の出来が違ってくる。|
| LLM | 大規模言語モデル（Large Language Model）の略称、インターネット上などの膨大なテキストをディープラーニングにより学習し、対話型AIサービスの中核を担っている。|
| LLM kinds | LLMの種類で汎用型、コード特化型や軽量・高速モデルなどがある。 |
| AI Agent |目標に対して自律的に計画を立て、ツールを使ってあるたすくを実行から完了までしてくれるAI。 |
| Autonomous AI | Agentの一種であり、、人の確認なしに目標達成まで自分の判断で動くAI|
| RAG | 検索、学習してから答える仕組み。文書などを読み込んで正確に答えさせたり、ハルシネーションを抑えてくれる用途で用いられる。　|
| OCR | 画像やPDFに写っている文字を読み込んで文字データにする技術。 |
| Plan Mode |　いきなり実行せず計画の提案するモード。作業が複雑な場合に便利。|
| Skills | AIに特定の作業をこなすための能力を追加する仕組み。 |
| AGENTS.md | AIエージェント向けのプロジェクトの説明書をかいたファイル。　|
| CLAUDE.md | AGENTS.mdのClaude Code版 |
